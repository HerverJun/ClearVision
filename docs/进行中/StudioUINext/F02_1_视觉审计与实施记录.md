## 2. 审计方法

- Visual Audit Owner：只读检查全部 F02 正式页面、现有截图、tokens、Shell、controls、states 与 Design Lab。
- Accessibility & Interaction Owner：只读检查 light/dark 对比度、键盘、focus、ARIA、短屏、density 与 reduced motion。
- Evidence Owner：冻结入口 SHA 的 Release publish，并通过现有唯一 WebView2 runner 串行生成 before 证据。
- 主协调：复核源码与截图，独占共享 tokens、Shell、controls、states、Design Lab、测试、文档与最终集成。

审计时确认 `3ae4abc6..15fc82d7` 之间 StudioUI 视觉源码无差异；历史 F02 截图可用于问题定位，
正式 before 证据仍重新冻结在入口 SHA `15fc82d7`。

## 4. 无障碍与交互问题矩阵

| ID | 严重度 | 代码事实 | F02.1 校准方向 |
| --- | --- | --- | --- |
| A01 | P1 | ProductLayout 已有 `main`，各正式路由页根节点再次使用 `main`。 | Shell 保留唯一 main，路由页根改为 section/div；增加唯一 main/h1 guard。 |
| A02 | P1 | light muted `#7c8899` 对白色仅约 3.60:1，并用于 11/12px 文本、hint 与 placeholder。 | 可读 muted token 在 light/dark raised/page surface 上均达到 4.5:1。 |

| A04 | P1 | 输入控件清除 outline，仅保留低透明 focus ring。 | 使用至少 2px 的实色技术蓝 focus-visible 轮廓，并覆盖 light/dark。 |
| A05 | P1 | 无 skip link；SPA 路由切换后焦点停留在旧导航/触发器。 | 增加“跳到主要内容”、可聚焦 main，并在正式路由完成后转移焦点。 |
| A06 | P2 | 混合 input/select/button 的 CvToolbar 声明 APG toolbar，但只对部分子控件执行方向键模型。 | 筛选区使用 group + 自然 Tab；纯按钮 toolbar 保留方向键模型。 |
| A07 | P2 | 静态 empty/权限/404 都是 live region；同页多个状态可能重复播报。 | 仅动态 loading/error 使用 live region，静态状态使用普通 region/section。 |
| A08 | P2 | 1366×600 只验证截图/overflow，未验证 sticky sidebar 中聚焦项始终可见。 | sidebar 使用 viewport 高度和独立纵向滚动，增加短屏键盘可见性测试。 |
| A09 | P2 | Product Shell 缺少 landmark、skip/focus-route、contrast、forbidden 视觉证据。 | 扩展现有 Playwright 与 unit guard，不创建第二 runner。 |

## 5. 页面特例

| 页面 | 当前特例 | 本轮处理 |
| --- | --- | --- |
| Overview | 四块内容全部卡片化，DescriptionList 和快速入口继续嵌套描边。 | 保留四块业务内容，改为轻摘要分区、行式入口和更稳定列宽。 |
| Projects | 搜索动作与字段 baseline 不齐，Panel 内再次套 Table 框。 | filter group 对齐 control baseline，Panel/Table 只保留一层边界。 |
| Operators | 筛选占两行，compact 到约 y=404 才进入表格，dark 网格线过重。 | 收敛筛选宽度与 panel chrome，强化主/次标识，弱化表格外框。 |
| Stations | 运行摘要内再套 6 格描边指标，关键列表被推迟。 | 指标改为单层分隔带，状态色只用于值与 badge。 |
| Results | 筛选 panel 高，分页大小孤立换行，数据区进入过晚。 | 缩小字段最小宽度，形成稳定 filter grid/rail，减少无效空白。 |
| Unauthorized | 用户区、Shell warning、capability 状态重复。 | Shell compact status 保留原因和重新检查；主状态只保留一次关键说明。 |
| Forbidden | 与 Unauthorized 视觉近似，身份有效但无权限的语义不突出。 | 保持独立文案和中性/琥珀层级，不画成网络或 NG 错误。 |
| 404 | 自建大号丹红数字和大片空白。 | 复用统一 not-found state；404 降为 meta，不借用品​​牌红。 |
