## 核心合同与安全语义

核心提交 `9c472857f1b4fdf0565625a26dc2b5334a1c532e` 完成以下收口：

- `/api/settings` 带 `saveScope` 的请求只接受 General、Storage、Runtime、Security；目标 section 必须存在且匹配，顶层和 section 内重复字段、未知字段、跨 section 字段、缺失 section 以及类型或范围错误在进入配置保存 authority 前拒绝。
- 保留必要的 Legacy `users -> security` 兼容；`runtimePreviewPilot` 继续只能走 developer-only endpoint，普通 Runtime scoped write 明确拒绝；`SessionTimeoutMinutes` 作为历史只读投影，不再进入有效策略保存；不新增 conditional revision，不修改配置默认值。
- General 标题、Storage 非负数和枚举、Runtime 非负数、Security password/lockout 下限由后端先校验。真实密码合同下限统一为 6，后端创建/重置/配置路径均拒绝低于下限的值。
- Settings write coordinator 增加 section 定向取消、全局 invalidate/dispose 和 operation kind；read、write、runtime、account、database 结果分别投影。mutation 的网络中断、取消或 decode 失败保留为 unknown outcome，要求重新读取，不显示成“未保存”；read/decode failure 仍单独归类。
- Settings owner 与现有 leave guard 共享草稿/pending/unknown 状态。分组切换、route leave、role/session 变化和 dispose 都不再静默丢弃 dirty draft，也不会让已卸载面板的 mutation 在后台失去可观察性。
- 修改本人密码复用现有 auth lifecycle：成功后清除 token、结束认证 session、销毁受保护 runtime 并进入重新登录；密码字段在成功、失败、取消和卸载路径清空。
- User authority fail closed：当前 Admin 不能自删除、自停用或自降级；删除、停用或降级最后一个有效 Admin 被后端拒绝。UI 提示只是辅助，最终规则在服务端。

这些修复补充了历史 G1-R 对 endpoint-level permission 和 owner gate 的结论，但没有创建第二 HTTP、Owner、EventBus、HostBridge、Canvas 或持久化体系。

## 设备工作台语义

设备提交 `e6962cbad779dfa3c51489214f8a9fb7a6ad42fe` 完成以下收口：

- PLC mapping 保存前比较本地协议 draft 与服务端 `ActiveProtocol`；不一致时拒绝保存并要求先保存协议。协议和 mapping 成功后都重新读取服务端 projection，mapping baseline 使用服务端返回值。
- TCP Profile 使用稳定本地 identity；已有 Profile ID 只读。dirty/new/未保存 Profile 不能 connect、server start 或 send，运行操作只接受已保存版本；首次进入面板实际读取 profiles、runtime status 和 frame。保存 Profile 不自动连接或启动 Server，合法 IPv6 等后端支持的地址格式不被前端无故拒绝。
- Camera `Disconnected` 不再被识别为 connected；binding 成功后重新读取服务端 binding projection，409 保持 fail closed 且不覆盖 authoritative state。
- Camera preview diagnostics 覆盖 controller、session、frame loop 和 blob URL；stop、panel/route leave、invalidate、权限变化和 dispose 后计数及 blob 资源归零，远程 stop 保持 best-effort，并继续使用既有 CameraManager/preview owner。
- 总览和 section 状态改为显示真实 PLC/TCP/Camera 接入状态；Generic section 按角色显示 Admin 可编辑、Engineer 只读。清除了“本轮不保存”“只读壳层”等过时产品语义。
