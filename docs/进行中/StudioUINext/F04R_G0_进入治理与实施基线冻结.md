其余注入到 `window.__CLEARVISION_STARTUP__.featureFlags` 的值来自该运行进程加载的 `StudioOptions`。Runner 可显式请求 `LEGACY_DEFAULT`、`NEXT_PILOT` 或 `NEXT_FULL_CANDIDATE`，但这是隔离证据配置，不改写正式默认值。本轮没有运行 runner，也没有启用 `NEXT_FULL_CANDIDATE`。

### 3.5 flag 漂移

- Desktop `WebView2Host.BuildStudioUiFeatureFlags` 会注入 `Studio2.Workspace`、legacy capability flags 和两个 ROI 工具 flags。
- 当前 Router/Navigation 使用 `Studio2.StationsRead`，但 Desktop WebView2 注入表没有该 key；真实 WebView2 中 `/stations` 因此不能由现有正式配置开放。
- StudioUI 产品代码实际只消费 `Studio2.Workspace`、`Studio2.StationsRead`、`Studio:CircleSearchV2ToolEnabled`、`Studio:NPointCalibrationWorkbenchEnabled`。`Studio2.Settings`、`Studio2.Inspection`、`Studio2.ResultsReview`、`Studio2.AiPanel` 等当前只属于 legacy/Host 投影，不能冒充 Next capability 已挂载。
