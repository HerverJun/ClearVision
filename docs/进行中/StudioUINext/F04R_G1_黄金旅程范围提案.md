## 3. 当前可完成的连续片段

在 Browser fixture 或获批的 `NEXT_PILOT`、已有工程/基础参数前提下，当前可连续完成：

```text
登录 -> 创建空白工程 -> 打开工作区 -> 添加算子 -> 编辑基础参数
-> Preview/ROI -> 保存/冲突恢复 -> Formal Run/Stop/Reconcile
-> 成功结果详情与诊断
```

这不是黄金旅程 PASS，原因是：

- 正式默认仍关闭 StudioUI/Workspace；
- 特殊参数、全局变量、最终判定、导出不可完成；
- stable camera Preview 合同尚未同步；
- Browser fixture 不能替代真实 WebView2、DPI 或真实端点。

## 6. Prompt 2 必须由产品负责人批准的决策

1. 登录后的默认落点采用 `/projects` 还是保留 `/overview`。
2. 黄金旅程第二步只要求 blank create，还是必须包含 versioned Project import。
3. 特殊参数样板选择相机绑定/单帧捕获还是文件选择；推荐相机，但依赖 stable sync。
4. GlobalVariables 最小闭环是否包含 definitions、参数 binding、手动值与 source/target binding。
5. FinalDecision 最小闭环的候选输出、规则、校验与错误展示范围。
6. 成功/NG 是否自动进入结果详情；失败、取消、未知 outcome 是否留在 Workspace 并提供什么入口。
7. F04-R 的“可交付资产”选择 Admin runtime package，还是需要 editable Project export/import 合同。
8. Workspace Preview/Formal Run backend policy 是否收紧为 Engineer/Admin。
9. 检测结果在 F04-R 只做详情/诊断，还是同时纳入 evidence export。
10. 未实现的检测、AI、设置、监控操作域在 pilot 中采用真实隐藏，并继续阻塞正式默认入口。
