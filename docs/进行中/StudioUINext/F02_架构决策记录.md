## 2. 产品边界

F02 Goal 1 建立正式产品外壳、共享只读查询地基和首批只读页面，不改变后端业务权威：

- Project、Flow、GlobalVariables、assets 与 `PersistenceRevision` 仍由现有 Application
  Service 和 `ProjectSaveCoordinator` 管理；
- StudioUI 只持有 UI 投影、查询状态、可丢弃缓存与外观偏好；
- 产品业务请求只允许 GET；不新增第二 endpoint、第二 client、第二保存链或前端持久化权威；
- `Studio:StudioUiEnabled=false` 保持不变，legacy 继续是默认入口；
- WebMessage bridge 只保留宿主能力适配，不承担业务执行；
- Goal 1 不实现 Operator Catalog、Station、Results、Flow、Preview、ImageCanvas、ROI、写操作、
  Station SSE、认证写操作或入口切换。

## 3. Composition 与 owner

- `ProductLayout` 是唯一正式产品 Shell owner；
- `InternalLabLayout` 只承载 `/labs/**`，不出现在正式导航；
- capability 关闭或路由离开时必须真实 unmount/dispose；CSS 隐藏不算卸载；
- `sessionProjectionOwner` 是唯一常驻 `/api/auth/me` owner；
- `systemStatusOwner` 是唯一常驻 `/health` owner；
- Top Bar、Overview 与 Diagnostics 只消费共享投影，不重复轮询；
- Vue/Pinia 不长期持有 `AbortController`、EventSource、Canvas 或 WebView2 bridge；生命周期 owner
  暴露窄接口并负责 dispose。

## 4. 查询与缓存

`platform/api/apiTransport.ts` 继续是唯一网络 primitive。F02 在其上增加唯一 `readQuery`
编排层，职责固定为 decoder、query state、latest-request-wins、Abort、stale previous data、
错误映射与 session-generation protected cache。

受保护缓存 key 包含 session generation；401、token 消失或用户身份变化立即清空缓存并取消旧请求。
UI 本地 revision 只用于 stale 防护，不得与后端 `PersistenceRevision` 混用。

## 5. Design System 与文案

- 正式产品默认 `compact`，支持持久化 `light/dark` 与 `compact/comfortable`；
- 中性冷白/蓝灰承担大面积表面，丹红承担品牌与关键意图；
- brand、OK、NG、warning、info 与 canvas 技术蓝保持独立 token；
- 正式导航、页面标题、空状态、错误与辅助文案中文优先；协议名、代码名和标准缩写可保留英文；
- common states 统一覆盖 Loading、Empty、Error、Unauthorized、Forbidden、Not Found、Stale、
  Partial Failure；stale/partial failure 保留 previous data，不用全屏错误遮蔽。

## 6. 路由决定

- `/` 重定向 `/overview`；
- 正式路由：`/overview`、`/projects`、`/projects/:id`、`/diagnostics`、`/about`；
- `/labs/design` 与 `/labs/canvas` 使用 Internal Lab layout 且从正式导航隐藏；
- catch-all 显示正式 404，不重定向 Diagnostics；
- route meta 是标题、面包屑、layout 与认证投影的唯一前端声明入口，但后端仍是安全边界。
