## 5. 保持不变的架构边界

- Project、Flow、GlobalVariables 和正式 assets 仍通过既有 Application Service 与 `ProjectSaveCoordinator` 保存。
- `PersistenceRevision` 仍是正式并发身份；Vue/UI revision 只作可丢弃草稿与 stale 防护。
- Formal/Continuous runtime 仍由 `InspectionRuntimeCoordinator`、`InspectionService` 与 RuntimeHost 掌权。
- Runtime Package 仍使用既有 exporter/loader/validator 与 Station package store；没有第二包格式或仓库。
- Station registry、command store、journal、spool、SSE 和 last-known-good 仍由既有后端/Station owner 掌权。
- Results/evidence 仍由既有 repository、history/compare/evidence endpoint 掌权；没有第二 result/evidence store。
- 没有新增第二 HTTP client、EventBus、ServiceRegistry、HostBridge、Canvas 内核、save client 或 WebMessage 执行通道。
- 默认 `StudioUiEnabled=false`、默认 flags、Legacy 入口和 Legacy 文件未改变。
