## 1. 产品语义

相机绑定是 ImageAcquisition 节点的正式参数选择；单帧捕获是可丢弃调试输入，不是 Project asset、正式运行输入或 Inspection result。捕获帧必须携带采集节点身份，只有该采集根节点到目标节点的可达路径可以消费它。

冻结流程：

```text
选择 ImageAcquisition 节点
-> 读取既有 camera bindings
-> 选择 binding 并写入 Flow parameter draft
-> 请求单帧捕获
-> 建立 frameId + sourceNodeId + sourceSignature
-> Preview 对 source/target/project/revision 做失效检查
-> 后端仅在本次 Preview 的克隆 Flow 中把相机采集替换为外部图像
-> Preview/Image/ROI 消费该帧
```

不得把相机方案替换为文件选择器，也不得把捕获帧写入 localStorage 或正式 Project payload。

## 6. 错误、取消与权限

| 条件 | 行为 |
|---|---|
| binding 空/删除/404 | 字段错误定位到相机绑定；清除可丢弃帧；不得回退到任意旧图像 |
| binding 无连接/设备离线 | 显示设备、影响和重新发现/选择动作；不改 Project 参数 |
| 403 | binding/capture 继续服从 `CanOperateHardware`；不把权限错误显示为相机离线 |
| 捕获取消或 route unmount | Abort 请求；晚到 blob 不进入 Preview；释放 URL/订阅 |
| source 节点删除、禁用、改 binding/trigger/exposure/gain | 立即使 frame invalid，并要求重新捕获 |
| target 不可从 source 到达 | 不向该目标注入 frame，不把其他节点的图像当输入 |
| 后端 `PREVIEW_CAPTURED_FRAME_SOURCE_INVALID` | 保留 Canvas/Inspector，清除失效帧，显示稳定中文原因 |
| MIME 未知 | fail closed 为不可展示附件；不强制解释成 PNG |
