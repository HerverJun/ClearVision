## 工程闭环

- Pilot 登录后默认进入 `/projects`；导航只保留工程、当前工程上下文中的流程、检测结果。
- Camera owner 负责绑定、单帧捕获、取消、失败恢复、帧身份、旧帧失效与 dispose；浏览器旅程使用明确标注的 fixture frame，未冒充真实相机。
- GlobalVariables 支持 definition CRUD、初始值、source/target binding、类型/引用校验、apply/cancel/dirty 与只读运行值；通过统一 Project `PUT` 进入现有 `ProjectSaveCoordinator`。
- FinalDecision 使用真实候选输出、规则/阈值、后端校验、结构化字段错误、失效候选、dirty/hash/revision，并随 Project 正式保存；没有独立保存 endpoint。
- Formal Run/Stop/Reconcile 继续使用现有 authenticated HTTP/SSE 权威；成功/失败/取消/unknown outcome 均留在 Workspace，当前结果通过显式入口查看。
- Results 详情包含诊断、Evidence manifest、单条 Evidence export 与 Project revision/Decision hash 追溯字段。
- Admin Runtime Package 只从已正式保存、无 dirty 的工程导出，不携带临时 Flow override。
- Vue 只组合 UI；canonical FlowCanvas/ImageCanvas、唯一 transport、HostBridge、EventBus 与保存链均未重造。
