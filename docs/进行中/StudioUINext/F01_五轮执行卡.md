# F01 五轮执行卡

## 1. 总体 DAG

```text
Prompt 1 退役与构建地基
  -> Prompt 2 Host 与最小 Platform
    -> Prompt 3 Design Foundation
      -> Prompt 4 Canvas 与真实 WebView2
        -> Prompt 5 最终收口与 F02 输入
```

上一轮未通过本轮门禁时，不自动进入下一轮。

## 2. Prompt 1｜退役与构建地基

状态：`IN_PROGRESS`

唯一 owner：主协调 owner。共享文件、`.csproj`、CI、Router、package/lockfile、ADR 和架构守卫不得拆分给第二 owner。

交付：

- Git、远端、upstream、worktree 与稳定线新增提交审计；
- 权威计划和 README 采用五轮方式；
- FrontendV2 source/build/Host/config/CI/V2-only tests 完整退役；
- WebView2 runner、DPI、CI 代码事实；
- F01 ADR；
- 从零建立 StudioUI Vue 3 + strict TypeScript + Vite + Router + Pinia dependency + Vitest + ESLint + vue-tsc；
- `/studio/` base、hash router、manifest、默认无 source map、可注入输出目录；
- `/labs/design`、`/labs/canvas`、`/diagnostics` 最小占位；
- Desktop build/publish 将资产从 `obj` 复制到 output/publish `wwwroot/studio`；
- StudioUI 与 FrontendV2 退役架构守卫；
- frontend、Desktop Debug、focused tests、legacy regression、Release publish 和 publish audit。

停止边界：

- 不新增 `/studio` Desktop 启动选择；
- 不新增 `StudioUiEnabled`；
- 不新增 StartupConfigV1 或 startup reader；
- 不实现真实 HostBridge/API adapter；
- 不实现 Design Lab、primitives 或 Canvas；
- 不运行或新增 WebView2 StudioUI scenario；
- 不开始 Prompt 2。

通过标记：

```text
FRONTEND_V2_RETIREMENT=PASS
STUDIO_UI_BUILD_FOUNDATION=PASS
LEGACY_BASELINE=PASS
PROMPT_2_READY=YES
```

任一关键门禁失败则使用 Prompt 1 约定阻断码并停止。

## 3. Prompt 2｜Host 与最小 Platform

状态：`NOT_STARTED`

范围：Desktop Host、`/studio`、`StudioUiEnabled`、StartupConfigV1、startup reader、minimal Host/API platform。

前置：Prompt 1 全部门禁通过且工作区/远端状态已复核。

停止边界：不实现 Design Lab 或 Canvas。

## 4. Prompt 3｜Design Foundation

状态：`NOT_STARTED`

范围：design tokens、representative primitives、Design Foundation Lab、browser fixture、central Playwright。

前置：Prompt 2 Host/startup/platform 门禁通过。

停止边界：不接入 FlowCanvas，不迁移业务 capability。

## 5. Prompt 4｜Canvas 与真实 WebView2

状态：`NOT_STARTED`

范围：existing FlowCanvas canonical adapter、fixture、interaction、lifecycle、identity、WebView2 runner 泛化、Debug/publish WebView2、DPI 分层证据、标准化性能 A/B。

前置：Prompt 3 Design/browser 门禁通过。

停止边界：不创建第二 Canvas，不迁移正式业务 capability。

## 6. Prompt 5｜最终收口

状态：`NOT_STARTED`

范围：全量回归、publish/no-Node 本机证据、最终 architecture guards、用户视觉确认、GitHub Actions、F01 最终报告、技术债和 F02 输入。

前置：Prompt 4 Canvas/WebView2/DPI 门禁通过。

完成条件：满足 F01 完整开发计划的 DONE 门禁；否则保持 `AWAITING_VISUAL_CONFIRMATION`、`AWAITING_CI` 或相应 `BLOCKED_*`，不得启动 F02。
