## 修改范围

### 最小共享视觉语言

- 新增 `design-system/patterns/workbench.css`，统一专业工作台控件高度、边框、圆角、hover/focus/disabled、标题说明、状态条、错误区、技术详情和可复制值。
- tokens 只增加 workbench 语义别名，继续复用既有 density、spacing、radius、border 和 surface；没有重写 Design System。
- Runtime Package 改用同一 technical-detail、copyable-value 和 status 表达，减少 capability-local 样式漂移。

### Camera Binding

- 增加明确的“相机绑定”标题、用途说明和状态徽标。
- 连接状态、触发方式使用中文用户语义；绑定 ID、设备 ID、单帧 ID 进入折叠技术详情并支持复制。
- 捕获、取消捕获、刷新使用共享按钮体系；捕获中、成功、失败、只读状态使用统一状态层级。

### GlobalVariables

- 显示名称、类型、初始值作为主要编辑信息；内部名称和变量 ID 进入技术详情，新建时保持可见以避免隐藏必填项。
- 类型改用“文本 / 整数 / 数值 / 布尔值”中文标签；`session`、`ResultPath` 等用户层混杂文案已清理。
- 字段错误优先显示中文解释，诊断码和字段路径进入可展开诊断信息。
- dirty、readonly、error、applied 状态统一为状态徽标 + 状态说明；底部继续使用取消 / 应用到工程草稿，不改变保存链。

### FinalDecision

- 完成候选类型、规则、比较符与信号缺失策略的中文语义。
- 用户层优先显示来源算子、输出、判定方式和保存范围；算子 ID、草稿修订、草稿指纹进入折叠技术详情并支持复制。
- 校验错误优先显示中文消息，code/field 进入诊断层。
- readonly、dirty、validating、error、configured 状态统一；无 dirty 时禁止重复应用，校验中显示 loading 状态。

### 已完成区域复核

- Shell、Workspace、Inspector、Preview、Results、Runtime Package 没有新增 Route、API、Owner 或 IA。
- Canvas、Preview 和 Results 继续承担视觉主体；本轮只消除工作台局部样式与技术信息层级漂移。
- canonical FlowCanvas、ImageCanvas、Project save、Formal Run、Evidence 与 Runtime Package authority 均未改变。
