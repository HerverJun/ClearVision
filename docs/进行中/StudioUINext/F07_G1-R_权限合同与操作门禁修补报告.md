## 2. Settings owner 操作门禁

`SettingsOwner.enqueueEndpointOperation(section, endpointId, task)` 现在必须解析 `SETTINGS_ENDPOINT_MATRIX` 中的具体 endpoint contract。通过以下检查后，任务才会进入原有 section coordinator：

- endpoint 未知：fail closed；
- endpoint 属于 `SETTINGS_EXCLUDED_ENDPOINTS`：fail closed；
- endpoint section 与请求 section 不一致：fail closed；generic `/settings` 只接受其四个 `genericScopes`；
- `uiPermission=settings-route` 只代表 route 可见性，不能直接执行操作；
- `uiPermission=engineer-or-admin` 允许 Engineer/Admin；`uiPermission=admin` 只允许 Admin；Operator 全部拒绝；
- task context 携带已解析的 endpoint contract，避免 task 仅凭 section 或 route role 执行。

coordinator 仍只按 `SettingsSection` 串行排队；没有新增第二写入口或 HTTP client。当前仍没有具体 section save function，endpoint operation 只是受控骨架。
