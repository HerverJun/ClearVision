本文只记录 F02 可交给后续阶段的稳定地基与禁止边界，不批准也不提前实现 F03 capability。

## 2. 可继承地基

| 地基 | F02 已冻结事实 | F03 使用约束 |
| --- | --- | --- |
| Product Shell | 唯一 `ProductLayout`、正式中文导航、状态页与 Labs 隔离 | 不创建第二 Shell；flag 切换必须真正 unmount/dispose 旧 owner |
| Design System | light/dark、compact/comfortable、状态色、focus、ARIA、reduced motion | 复用 primitives/tokens；不引入页面私有平行 token 体系 |
| HTTP/read query | 唯一 `apiTransport.ts` + `readQuery` | 新 endpoint 先做合同冻结；组件不得直接 fetch，不建第二 client |
| Session/status | 唯一 session projection 与 system status owner | 不复制 token、health timer、401 generation 或受保护 cache |
| Router/navigation | F02 产品路由、route meta、404/401/403 与 Labs 路由隔离 | capability 只有一个 mounted owner；隐藏 DOM 不算卸载 |
| Fixtures | 200 operators、500 results、混合 enum 与双轴 outcome | schema/source SHA 必须继续记录；fixture 不成为业务 authority |
| Evidence runner | Browser fixture、WebView2、performance、publish/no-Node 参数化 runner | 继续复用，不创建平行 runner；真实 DPI 与模拟 DPR 分开报告 |
| Host boundary | StartupConfigV1、WebView2 host adapter、`StudioUiEnabled=false` | WebMessage 只保留宿主能力，不绕过 authenticated HTTP/SSE authority |

## 3. F02 已冻结产品合同

```text
AUTH_ENTRY_DECISION=PRESEEDED_SESSION_PREVIEW_ONLY
PRODUCT_REQUEST_METHODS=GET_ONLY
OPERATOR_CONTRACT_GATE=PASS
F02_OPERATOR_CONTRACT_SCOPE=CATALOG_IDENTITY_AND_CURRENT_BRANCH_RUNTIME_METADATA
STABLE_LINE_FULL_OPERATOR_CONTRACT_SYNC=DEFERRED
STATION_SSE=DEFERRED
RESULTS_DUAL_AXIS=REQUIRED
```

- Projects、Operators、Stations、Results 目前均为只读投影；
- Results 必须继续保留 Execution/Decision 双轴与九类 canonical outcome；
- Station Admin detail 403 只降级增强区，不能遮蔽普通详情、结果或 health；
- Operator quality/readiness、conditional rules、image-depth contracts 与 `MeasurementEvidence` 未纳入 F02
  identity gate；若 F03 需要展示，必须重新冻结 payload、decoder、执行语义和适用测试项目；
- Station SSE 未批准；若启用，先有共享 authenticated stream ADR，覆盖 Bearer、授权、脱敏、replay、
  reconnect、并发上限、hidden/unmount/flag-off dispose，不得建立第二 stream client。

## 4. Flow / Preview 迁移红线

F03 不得以“新 UI 迁移”为名形成第二业务权威：

```text
Vue/Pinia/DOM/localStorage != Project authority
Vue/Pinia/DOM/localStorage != Flow authority
Vue/Pinia/DOM/localStorage != GlobalVariables authority
Vue/Pinia/DOM/localStorage != execution/result authority
```

- Project、Flow、GlobalVariables 和正式 assets 的写入必须复用既有 Application Service，并最终进入
  `ProjectSaveCoordinator`；不得新增第二 save endpoint/client/queue；
- UI local revision 只用于草稿与 stale 防护，正式并发身份仍是后端 `PersistenceRevision`；
- 现有 `FlowCanvas`、`ImageCanvas`、ROI 与 Preview 命令式内核只能通过窄 adapter/lifecycle owner 接入；
  Vue 不直接持有实例，owner 必须 dispose listener、timer、RAF、observer、AbortController、blob URL；
- Feature Flag 关闭或切换时旧 owner 必须 unmount/dispose 并停止请求、订阅、timer、SSE 和写操作；
- 不得建立第二 Canvas kernel、HostBridge、EventBus、ServiceRegistry、HTTP core 或状态树后再事后合并。

## 5. Runtime、Station 与执行边界

- AgentRun、EventStore、终态 reservation、replay/recovery、Workspace Snapshot 不迁入前端；
- Runtime Package、RuntimeHost、Inspection 协调、正式结果持久化和 Station 现场链路保持后端权威；
- 正式执行/检测控制继续使用 authenticated HTTP/SSE；WebMessage 不新增旁路执行通道；
- 真实 camera/PLC/Station/工业显示/现场验收未在 F02 执行，F03 不得以 fixture、静态 Chromium 或
  WebView2 本机 smoke 代替。

## 6. F03 启动前门禁

1. 明确 F03 capability 清单、唯一 owner、文件白名单、共享文件协调人和回滚边界；
2. 对所有新增 endpoint、permission、decoder、写入和 stream 先完成合同冻结；
3. 对 Flow/Preview 迁移给出单 authority、save chain、revision、adapter 与 dispose 设计；
4. 保持 `Studio:StudioUiEnabled=false`，除非独立入口切换 Goal 完成真实登录、Release、WebView2、
   no-Node、DPI、回退和现场门禁；
5. 延续 F02 的 GET-only、single-owner、Labs isolation、中文 copy、Browser/WebView2/performance/
   publish evidence；未运行项继续写 `NOT PERFORMED`；
6. 用户后续仅确认 F02 视觉不需要创建第 4 个开发 Goal，也不自动授权 F03。
