## Operator 产品投影

Operator 继续使用现有 authenticated session、Profile 和后端 policy；没有新增角色 authority，也没有放宽 `CanEditProject` 或 `CanOperateHardware`。Next 的 Operator 投影只保留概览、工程只读摘要、检测结果、工作站只读状态、算子信息和关于页面。

## Rollback Host 修复

历史失败的真实根因是 Desktop Host close/flush 超过 15 秒，不能把它归因于单一超时参数。当前修复把 Workspace flush、AI Workspace flush、WebView2 dispose、Kestrel host-stop 和 process-exit 分阶段记录，并保留生产环境的人工强制关闭确认。

Evidence runner 的 unattended 模式必须由显式参数启用，并要求数据库、运行目录、WebView2 user-data、日志和 diagnostics 全部位于仓库 `.tmp` 隔离边界；强制退出会写入诊断记录，未知或强制退出结果不会被判为成功，任何工程和数据库文件都不会由该路径删除。

本轮只完成代码修复、定向 Desktop 测试和 runner 静态解析，没有运行真实 WebView2 rollback drill。因此不能声明 `ROLLBACK_DRILL=PASS`、数据零损失或最终候选无 owner 泄漏；这些结论仍待干净提交后的实际演练。
