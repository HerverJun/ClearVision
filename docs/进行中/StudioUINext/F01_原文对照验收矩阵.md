- push 与最终 SHA CI 是提交后外部证据；仓库内提交候选状态为：

```text
F01_STATE=AWAITING_CI
```

最终 SHA CI PASS 后、用户尚未确认视觉时，只能转为 `F01_STATE=AWAITING_VISUAL_CONFIRMATION`；不得标记 DONE，不得启动 F02。
