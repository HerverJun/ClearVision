## 1. 冻结口径

黄金旅程以用户完成真实任务为准，不以 route、页面或按钮存在为准。Legacy 是成熟操作语义基线，Next 当前代码是能力与架构事实，后端 DTO、Application Service、`ProjectSaveCoordinator`、Inspection/Result/Runtime authority 是写入和执行权威。

## 4. 状态、取消与恢复矩阵

| 状态 | 冻结行为 |
|---|---|
| loading / empty | 保留对象上下文和可取消读；空态说明缺少什么以及下一步，不伪造示例业务数据 |
| dirty | 仅 Project draft 标记；Preview frame/result/runtime values 不进入 dirty；离开由唯一 Leave Guard 处理 |
| 401 | `AuthLifecycleOwner` 单点 quarantine；保留 save/run reconcile identity；重新登录后先协调再恢复 |
| 403 | 后端 policy 是 authority；隐藏无权限命令但仍正确呈现后端 403，不降级为网络失败 |
| 404 | 工程/结果/相机 binding 明确不存在；停止对该 identity 写入；返回列表或重新选择 |
| 409 | 保存使用 revision conflict；运行中修改/导出显示当前占用；不得自动重试写入 |
| unknown outcome | Save 用 fresh Project GET；Run/Stop 用现有 reconcile；Runtime Package 无可靠 mutation identity，禁止自动重试并显示“结果未知”及人工核对动作 |
| cancel | 读请求取消不报失败；相机捕获取消丢弃晚到帧；变量/判定编辑取消恢复打开前 draft；ROI 保留现有放弃；Stop 不等于客户端取消 |
| recovery | 所有恢复都回到原 project/node/selection；只有用户点“查看本次结果”才离开 Workspace |
