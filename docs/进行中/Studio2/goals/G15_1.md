- 新增/变更契约：
  - 新增默认关闭启动 flag：`Studio2.PropertyPanel`，宿主配置键 `Studio:PropertyPanelCapabilityEnabled=false`。
  - `app.js` 在 bootstrap 时只读一次 `window.__CLEARVISION_STARTUP__.featureFlags["Studio2.PropertyPanel"]`，flag off 创建 legacy owner，flag on 创建 `PropertyPanelCapabilityOwner`。
  - `PropertyPanelCapabilityOwner` 通过 `PropertyPanelCapabilityAdapter` 订阅 `FlowCanvasAdapter.subscribeSelection()`/`subscribeStructureState()`，通过 `FlowCanvasAdapter.patchNodeParameters()` 写参数。
  - `PropertyPanel` 增加 `destroy()`，legacy selected-operator subscription 收敛到 owner dispose。
- 行为清单和切换矩阵：
  - 旧 owner：`app.js` 的 `initializePropertyPanel()`。
  - 旧 mount 位置：`new PropertyPanel('property-panel', ...)` 挂载到 `#property-panel`。
  - 旧 subscription：`trackedSubscribe(subscribeSelectedOperator, ...)` 监听旧 app 层 selected operator signal；`PropertyPanel` 内部挂载 `FilePickedEvent`、form change/click listeners、`PreviewPanel`/ROI/Calibration 子面板 subscriptions。
  - 旧 timer：`PropertyPanel.showToast()` 使用短时 `setTimeout`；`PreviewPanel` 由 `PropertyPanel` 内部挂载并可能调度 auto preview debounce；旧 owner 自身无常驻 interval。
  - 旧 write entry：`PropertyPanel.onChange()` -> `app.js` 将 `getSelectedOperator().parameters` 复制到 `flowCanvas.nodes.get(operator.id).parameters`，再调用 `flowCanvas.markFlowStructureChanged('parameter-change')` 与 `syncCurrentProjectFlowFromCanvas()`。
  - 旧 destroy/dispose：`PropertyPanel` 当前没有顶层 `destroy()`；`clear()` 会销毁 `PreviewPanel`、`RoiEditorPanel`、`CalibrationDraftWorkbench`，但 app 级 selected-operator subscription 由全局 `subscriptions` 持有，没有 property panel owner 级 dispose。
  - 依赖 FlowCanvas 的方式：`app.js` 使用 raw `flowCanvas.nodes`/`markFlowStructureChanged()`；`PropertyPanel` 子功能通过 `serviceRegistry.get('flowCanvasAdapter') || serviceRegistry.get('flowCanvas')` 读取 revision、nodes、selectNode、structure subscription。
  - 依赖 selected node 的方式：`FlowCanvas.onNodeSelected` 构造 selected operator clone 并调用 `setSelectedOperator()`；旧 PropertyPanel 只订阅该 signal，不直接订阅 `FlowCanvasAdapter.subscribeSelection()`。
  - 参数写入路径：form input change -> `PropertyPanel._notifyValueChanged()` -> mutate `currentOperator.parameters` -> `onChangeCallback(values)` -> `app.js` raw FlowCanvas node parameter array replacement。
  - Preview/Result/GlobalVariables 是否被触碰：本轮审计未迁移 Preview Panel、Results/Review 或 Global Variables；旧 `PropertyPanel` 仍包含嵌入式 operator preview 与全局变量绑定控件，后续代码仅治理 Property Panel owner/mount/write，不迁移这些 capability owner。
- 切换矩阵：
  - flag off：`createLegacyPropertyPanelOwner()` 创建唯一 legacy `PropertyPanel`；V2 owner/adapter 不创建；legacy 订阅 selected operator signal；旧参数写入路径保持可用。
  - flag on：`PropertyPanelCapabilityOwner` 是唯一 mounted owner；legacy `PropertyPanel` 不构造、不 mounted、不订阅 `FilePickedEvent`/selected operator、不创建 `PreviewPanel`/ROI/Calibration 子资源、不写参数。
  - owner 切换：`initializePropertyPanel()` 先调用 `disposePropertyPanelOwner()`，释放上一 owner、取消 subscription 并从 `serviceRegistry` 注销。
- active owner / 唯一写入口：
  - active owner：flag off = `legacy-property-panel`；flag on = `property-panel-capability-v2`。
  - 唯一写入口：`PropertyPanelCapabilityOwner -> PropertyPanelCapabilityAdapter -> FlowCanvasAdapter.patchNodeParameters()`。
  - `patchNodeParameters()` 新增 opt-in `allowCreateParameters`，只由 capability adapter 使用以保持 legacy 参数定义补齐语义；默认调用行为不变。
- Legacy mounted / subscription / timer 状态：
  - flag off：legacy mounted/subscribed；V2 not mounted/no subscription/no timer/no write。
  - flag on：legacy not mounted/no subscription/no timer/no write；V2 mounted/subscribed via adapter/no interval timer/write via adapter。
  - 旧实现保留原因：未执行 Playwright/真实 WebView2 验收，且旧 `PropertyPanel` 仍承载 flag-off legacy parity、内嵌 operator preview 和全局变量绑定控件。
