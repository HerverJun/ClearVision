# G09C: Polygon and PointSequence Editing

> Stage: Geometry/Spatial
> Status: `DONE`
> Goal: Complete the shared interactions needed for polygon ROI editing and N-point calibration sample editing.

## Scope

[x] Polygon vertex create/insert/delete/drag/whole-move/select/cancel/commit/draft undo/redo.
[x] PointSequence order/select/drag/enabled-disabled/delete/ordinal display/draft history.
[x] Legacy `PolygonPoints` and `PointPairs` adapters.

## Explicit Non-Goals

- CoordinateAxis remains a read-only scene primitive.
- No calibration solving changes beyond honoring optional `Enabled=false` point-pair records.
- No formal calibration asset save.
- No second canvas, second geometry owner, or global undo bus.

## Policy

[x] Polygon editing fails closed for self-intersection, duplicate points, fewer than three valid points, out-of-bounds points, near-zero edges, and non-finite coordinates.
[x] Invalid polygons are not silently generated or repaired into parameters.
[x] `PolygonPoints` remains the legacy JSON string format: `[[x,y],...]`.
[x] `PointPairs` remains legacy JSON and supports flat, nested, and pixel/physical field names; optional `Enabled=false` records are ignored by runtime and scene projection.
[x] Scene overlays and editable overlays remain isolated by overlay group/owner.
