## 代码推断

本节只记录从当前代码读出的状态权威，不声明新增实现。

- Desktop 启动入口 `ClearVision.Product/src/ClearVision.Product.Desktop/Program.cs` 在启动 WebServer 后调用 `ProjectSaveCoordinator.RunStartupRecoveryAsync()`，并通过 `AgentRunEventStore.GetDefaultDirectory()` 参与单实例 store lease。
- `AgentRunEventStore` 以 `agent_run_events.jsonl` 和 `agent_run_summary.jsonl` 记录运行事件与摘要，是 AgentRun 运行事件的持久化权威。
- `AgentRunEventStreamService` 管理内存订阅、终态预约、终态提交、replay 和 SSE token；恢复时会从 `AgentRunEventStore` 还原 state。
- `VisionAgentBuildTerminalProjector` 将 Build 终态事件投影为 `ConversationSession` assistant turn、flow snapshot 和 `VisionAgentWorkspaceSnapshot` 更新；它依赖 `VisionAgentBuildProjectionJournal` 做幂等和冲突判断。
- `VisionAgentBuildProjectionJournal` 是 Build terminal projection checkpoint，不替代 AgentRun EventStore，也不是 Project/Flow 的正式保存权威。
- `ConversationalFlowService` 持有 `ConversationSession`、`VisionAgentWorkspaceSnapshot` 和 mutation receipt，负责会话状态持久化与 last-good backup。
- `ProjectService` 通过 `ProjectSaveCoordinator.SaveExistingProjectAsync()` 保存 Project metadata、Flow JSON 和 GlobalVariables schema。
- `ProjectSaveCoordinator` 的事务参与者是 `Project`、`Flow` 和 `VariableState`，使用 `Prepared -> CommitIntended -> Completed` manifest 阶段和项目级 gate 处理恢复。
- 前端 `projectManager.js` 的 `saveProject()` 通过 `/api/projects/{id}` 和 `/api/projects/{id}/flow` 写入后端，`saveGlobalVariables()` 通过 `/api/projects/{id}/global-variables` 写入后端。
- `app.js` 中 `cv_autosave_backup` 的 `localStorage` 只保存本机草稿备份，提示用户恢复后仍需点击“保存工程”写入正式工程库。

详细边界见 [`../状态权威与恢复边界.md`](../状态权威与恢复边界.md)。
