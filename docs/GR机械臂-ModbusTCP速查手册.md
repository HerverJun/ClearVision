# GR 机械臂(格力) ModbusTCP 通讯速查手册

> 来源:《GR机器人通信总线手册 v3.0-1》《GR机器人示教器手册 v3.0-1》(珠海格力智能装备)
> 现场设备:LAN2 IP = 172.16.87.12(默认),端口 502,MAC 6c-30-2a-46-63-ac,本机 172.16.87.222

## 1. 连接基本信息

| 项目 | 值 |
|---|---|
| 控制器型号 | GMEEMC06A 系列(EtherCAT 主站,伺服总线 EtherCAT CoE,周期 4ms) |
| ModbusTCP 网口 | **LAN2**,RJ45,100Mbps 全双工 |
| 默认 IP / 端口 | **172.16.87.12 : 502**(可改;LAN2 最多同时启用 4 个端口,端口范围 100-1000) |
| 角色 | 机器人 = ModbusTCP **服务器**,上位机 = 客户端 |
| 支持功能码 | **03** 读保持寄存器 / **06** 写单个 / **0x10** 写多个 —— 仅保持寄存器 |
| 字节序 | FLOAT 为**大端**,占 2 个寄存器(高字在前)。例 412.234 = 0x43CE1DF4 → [addr]=0x43CE,[addr+1]=0x1DF4 |
| 服务器开关 | 示教器:菜单→控制面板→监控→Modbus 开关(**默认关闭**)。开启后 LAN2 必须插网线,否则报警 3427 |
| IP/端口配置 | 控制面板→配置→通讯配置→IP Setting(LAN1/LAN2),改完**重启生效** |

开启方法:自动模式(钥匙开关拨左)→ 右下角快捷设置 → 外部自动 → Modbus 控制。状态栏图标变为 Modbus 控制模式。

## 4. 用户自定义数据交互区
- 保持寄存器 **0~124**(UINT16),可读可写。
- 机器人程序侧用指令 `ModbusWrite(addr, value, NumType)` 发送、`ModbusRead(addr, value, NumType)` 接收(NumType: SHORT/INT/FLOAT/DOUBLE)。
- **601** = 产量计数专用地址(INT16,最大 65535 自动清零),固定不可改。
- 这是与视觉/MES 交互自定义信号(如检测结果、触发握手)的主要通道。

## 5. 示教器要点(操作备忘)
- **钥匙开关**:左=自动,中=手动低速,右=手动高速。
- **使能开关**(背面三档):中间档上使能,松开/按死均断使能。
- **急停**:按下停机,顺时针旋转解除,再手动清报警。
- 薄膜键:Start/Stop(自动启停)、Mot(自动使能)、Jog(笛卡尔/关节切换)、V±(倍率±5%)、F1/F2 自定义。
- 权限:普通操作员(无密码)/高级操作员/系统管理员;长时间不操作自动降为普通操作员。
- 手动试运行:手动模式按住使能 + Start,松开即停。
- 程序结构:工程→main(入口)+子程序;运动指令(MovJ/MovL/MovC)只能在 T_Robot 任务;全局变量在 Share 工程。
- 自动运行:钥匙拨自动 → Mot 上使能 → Start;运行模式单步/单周/循环。
- 数据监控:控制面板→监控→数据监控,可实时看保持寄存器/信息化/Modbus 控制值(调联机时很有用)。
- 备份:U 盘,程序备份 Backup_Project_xxx / 参数备份 Backup_System_xxx。
- 事件日志:公用/运控/驱动/通信报警 + 操作记录。

## 6. 对接注意事项(工程实践)
1. 先决条件:示教器打开 Modbus 开关;要远程控制还需自动模式 + 外部自动(Modbus 控制)。
2. FLOAT 读取:C# 下需按大端组合两个寄存器,如 `BitConverter` 前先交换字序(word-swap 不需要,byte 内部是标准大端,NModbus 读出 ushort[] 后:`(uint)(reg[0]<<16 | reg[1])` → `BitConverter.GetBytes` 反转)。
3. 通电状态(437)不能作为在线判断依据,应以 TCP 连接/轮询超时为准。
4. 只用 03/06/0x10 功能码,线圈类功能码不支持。
