# M5 粘接螺母剪切拉拔试验细则

文件状态：试行稿  
适用目的：验收判定  
适用范围：M5 铝合金粘接螺母剪切拉拔试验  
默认加载方式：力控制匀速加载，100 N/s  
关键待签发输入：`F_design = ______ N`，`F_accept = 1.5 x F_design = ______ N`

## 1. 目的

本细则用于规定 M5 铝合金粘接螺母在复合材料板状样件中的剪切拉拔验收试验方法，获得每件样件的最大拉拔力、力-时间曲线、破坏时间和破坏模式，并依据设计载荷系数完成合格/不合格判定。

## 2. 范围

本细则仅覆盖 M5 粘接螺母剪切拉拔试验。试验样件为 90 mm x 25 mm x 6 mm 复合材料板状样件，中部粘接安装 M5 铝合金螺母。材料体系包括：

1. SYT55G/环氧复合材料样件。
2. M40J/氰酸酯复合材料样件。

本细则不覆盖 M4 粘接螺母上紧力矩承载试验、螺纹扭矩试验、长期疲劳试验或环境老化试验。

## 3. 依据与优先级

试验依据如下，若后续文件之间存在冲突，按以下顺序执行：

1. 产品图纸、设计输入或载荷规范中给出的 `F_design`。
2. 被验产品或工艺文件中规定的胶粘剂型号、表面处理和固化制度。
3. 本试验细则。
4. 试验设备操作规程和实验室质量体系要求。

签发前必须填入 `F_design` 的具体数值或来源文件编号；未填入时，试验可用于摸底记录，但不得作为最终验收结论。

## 4. 术语与符号

| 符号/代码 | 含义 |
|---|---|
| `F_design` | 产品图纸、设计输入或载荷规范给出的设计使用载荷，单位 N。 |
| `F_accept` | 验收阈值，默认 `F_accept = 1.5 x F_design`，单位 N。 |
| `Fmax` | 试验过程中记录到的最大拉拔力，单位 N。 |
| AD | 粘接界面脱开。 |
| CO | 胶层内聚破坏。 |
| SUB | 基材开裂、分层或压溃。 |
| NUT | 螺母、螺纹或金属接头损伤。 |
| FIX | 夹具滑移、装夹失效、加载偏斜或其他装夹无效。 |

## 5. 样件要求

### 5.1 样件尺寸与结构

1. 样件名义尺寸为 90 mm x 25 mm x 6 mm。
2. M5 铝合金螺母应粘接安装在样件中部。
3. 样件两端按图示方向标识为 A 端和 B 端。
4. 每件样件试验前应记录长度、宽度、厚度实测值；尺寸明显偏离制样要求或存在边缘破损、分层、污染的样件不得作为有效样。

### 5.2 分组与数量

| 组别 | 材料体系 | 螺母 | 有效样数量 | 建议样件编号 |
|---|---|---|---:|---|
| G1 | SYT55G/环氧复合材料 | M5 铝合金螺母 | 3 件 | SYT55G-M5-01 至 SYT55G-M5-03 |
| G2 | M40J/氰酸酯复合材料 | M5 铝合金螺母 | 3 件 | M40J-M5-01 至 M40J-M5-03 |

每组至少获得 3 件有效样数据。无效样不得计入 3 件有效样数量。

### 5.3 制样与粘接记录

每批样件应至少记录以下信息：

1. 复合材料批次、铺层/成型批次或样件来源。
2. M5 铝合金螺母批次、规格和外观状态。
3. 胶粘剂型号、批次、配比和适用期。
4. 粘接面表面处理方式、清洁介质和处理后等待时间。
5. 固化温度、固化时间、加压方式和固化后放置时间。
6. 粘接位置检查结果和 A/B 端标识照片。

若被验工艺文件已规定胶粘剂、表面处理和固化制度，应按该工艺文件执行，并在记录表中填写文件编号。

## 6. 设备与夹具

### 6.1 试验设备

1. 使用万能试验机或等效拉力设备进行试验。
2. 载荷测量精度不低于 1 级，设备应在有效校准期内。
3. 预计 `Fmax` 应落在载荷传感器满量程的 10%-90% 范围内。
4. 设备应能输出完整力-时间曲线，建议采样频率不低于 20 Hz。
5. 若设备支持位移或横梁行程记录，应同步保存位移/时间数据作为辅助分析项。

### 6.2 夹具与加载连接

1. 夹具应同时固定样件 A 端及 B 端，使样件板面保持稳定，避免试验过程中发生端部滑移、翘曲或偏载。
2. 拉拔连接件应与 M5 螺母可靠啮合，加载过程中不得顶碰样件板面、胶层或螺母外缘。
3. 力 F 的方向按原理图所示垂直于样件板面向外拉拔。
4. 力 F 到样件板面的距离目标值为 5 mm，建议装夹允许偏差为 ±0.5 mm，并在试验前记录确认值。
5. 夹具与拉杆应在试验前空载检查同轴性；肉眼可见偏斜或连接松动时不得开始正式试验。

## 7. 环境条件

建议默认试验环境为 23±2 ℃、50±10%RH。样件正式试验前应在该环境下放置不少于 24 h。若产品规范或环境适应性要求另有规定，应按上位文件执行，并在报告中说明。

## 8. 试验步骤

### 8.1 试验前确认

1. 核对试验任务单、样件编号、材料体系、螺母规格和有效样数量。
2. 检查样件外观，记录粘接区、螺母、A/B 端和边缘状态。
3. 测量并记录样件长度、宽度、厚度，以及螺母居中情况。
4. 确认设备校准状态、传感器量程、夹具编号和数据采集设置。
5. 填入 `F_design` 和 `F_accept`；未填入时不得签发验收结论。

### 8.2 装夹

1. 将样件 A 端和 B 端固定在夹具上，保证样件板面平直。
2. 将拉拔连接件与 M5 螺母连接，确认螺纹啮合可靠。
3. 调整加载轴线，使力 F 按图示方向施加，并确认 F 到样件板面的距离为 5 mm。
4. 记录装夹照片，照片应能识别样件编号、A/B 端和加载方向。

### 8.3 预加载

1. 以低载方式预加载至 20 N 或 `0.02 x F_accept`，取较大值；当 `F_accept` 未填入时，按 20 N 执行预加载。
2. 保载 5 s，检查夹具滑移、拉杆偏斜、样件异常声响或可见裂纹。
3. 若出现异常，应卸载、重新装夹并重新预加载；仍异常时，该样件不得进入正式试验。

### 8.4 正式加载

1. 载荷清零后启动数据采集。
2. 按力控制匀速加载，加载速率为 100 N/s，建议允许偏差为 ±10%。
3. 连续加载至出现明显破坏、载荷下降至峰值后 20% 以下，或达到设备/安全停止条件。
4. 试验过程中观察并记录可见变形、裂纹、胶层脱开、螺母松动和异常声响。
5. 试验结束后保存原始数据文件、力-时间曲线和破坏照片。

## 9. 数据记录

每件样件至少记录以下字段：

| 字段 | 记录要求 |
|---|---|
| 样件编号 | 与样件实体标识一致。 |
| 材料体系 | SYT55G/环氧或 M40J/氰酸酯。 |
| 尺寸实测值 | 长度、宽度、厚度，单位 mm。 |
| 螺母批次 | 记录规格、批次或供应信息。 |
| 粘接记录 | 胶粘剂、表面处理、固化制度和工艺文件编号。 |
| 环境条件 | 温度、湿度、放置时间。 |
| 设备与夹具 | 设备编号、传感器量程、夹具编号。 |
| 加载条件 | 加载方式、加载速率、F 到板面距离。 |
| 判定载荷 | `F_design`、`F_accept`。 |
| 结果数据 | `Fmax`、破坏时间、曲线文件名。 |
| 破坏记录 | 破坏照片、破坏模式代码、文字说明。 |
| 最终判定 | 合格、不合格或无效样。 |

## 10. 验收判定

### 10.1 单件判定

单件样件同时满足以下条件时判为合格：

1. `Fmax >= F_accept`。
2. 在达到 `F_accept` 前未发生 AD、SUB、NUT 或 FIX 类失效。
3. 力-时间曲线完整，峰值和破坏时间可追溯。
4. 装夹、加载方向和 F 到板面距离记录有效。

出现以下任一情况时，单件样件判为不合格：

1. `Fmax < F_accept`。
2. 低于 `F_accept` 前发生粘接界面脱开、螺母松动、基材异常开裂/分层或螺母/螺纹损伤。
3. 达到 `F_accept` 前出现非预期快速失稳，且经复核不是装夹无效导致。

### 10.2 组别判定

每个材料体系组别应有 3 件有效样。3 件有效样均合格时，该组判为合格；任一有效样不合格时，该组判为不合格。

组别报告应同时给出 3 件有效样的 `Fmax`、平均值、最小值、变异系数和破坏模式分布。变异系数仅用于过程稳定性评估，不作为默认合格判据；如上位规范另有要求，应按上位规范执行。

## 11. 无效样与复验

以下情况判为无效样，可补做 1 件，并在报告中说明原因：

1. 夹具滑移、拉杆松脱、加载轴线明显偏斜。
2. 数据采集失败、曲线中断、峰值缺失或文件损坏。
3. 样件编号、材料体系、粘接记录无法追溯。
4. 试验前已存在影响结果的明显制样缺陷，且该缺陷未被纳入验收对象。

以下情况不得按无效样处理，应作为不合格结果保留：

1. 有效装夹条件下 `Fmax < F_accept`。
2. 达到 `F_accept` 前发生 AD、SUB、NUT 类失效。
3. 同组样件出现重复的低载失效模式，表明工艺或结构存在系统性问题。

## 12. 报告要求

试验报告至少包括：

1. 试验目的、样件来源、材料体系、螺母规格和试验日期。
2. `F_design` 来源、`F_accept` 计算过程和验收判据。
3. 样件制备、粘接工艺、表面处理和固化记录。
4. 设备、夹具、传感器量程、校准状态和环境条件。
5. 每件样件的原始数据摘要、力-时间曲线、破坏照片和破坏模式。
6. 每组统计结果：平均值、最小值、变异系数、破坏模式分布。
7. 单件和组别判定结论。
8. 异常、无效样、复验和偏离本细则的说明。

## 13. 安全与质量控制

1. 试验区域应设置防护罩或等效防护，防止螺母、拉杆或基材碎片飞出。
2. 操作人员不得在加载轴线正前方观察。
3. 试验机限位、急停、传感器量程和夹具紧固状态应在试验前确认。
4. 原始数据文件、照片和记录表应随报告归档，不得只保留人工摘录结果。
5. 任何偏离本细则的操作，应在报告中记录偏离内容、原因和批准人。
