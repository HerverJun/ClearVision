# 算子资料

`docs/算子资料/` 是 ClearVision 算子文档的正式入口，包含算子目录、算子名片、算子手册、版本记录、闪卡和知识笔记。

## 正式入口

- [算子目录](./算子目录.md)
- [算子名片索引](./算子名片/CATALOG.md)
- [算子手册](./算子手册.md)
- [算子变更记录](./算子变更记录.md)
- [算子文档现状对齐说明](./算子文档现状对齐说明-2026-04.md)

## 当前口径

- 正式算子：158 个。
- 运行时元数据：158 个；旧显示名仅作为关键词/搜索别名保留，不新增算子身份。
- 正式名片目录：`docs/算子资料/算子名片/`。
- 英文路径兼容镜像：`docs/operators/`。
- 根目录兼容镜像：`算子资料/`。

## 维护规则

- 新增或修改算子元数据后，优先通过 `scripts/OperatorDocGenerator/OperatorDocGenerator.csproj` 生成目录、名片、版本记录和镜像。
- 不直接手改 `docs/operators/` 或根 `算子资料/` 作为事实源；这些目录只服务旧链接和兼容路径。
- 外部沟通统一使用 158 个正式算子口径；旧显示名只用于兼容搜索，不计为额外产品能力。
- 算子质量结论需要引用 `quality/evals/reports/operator_quality_matrix.md` 或专项证据报告，不能只引用名片中的质量分。
