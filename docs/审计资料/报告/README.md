## 维护规则

- 报告正文保留结论、数据来源、验证命令或证据路径。
- 如果报告产生待办，待办必须进入 `docs/进行中/` 或审计修复清单。
- 新报告文件名建议使用 `主题-YYYY-MM-DD.md`，稳定滚动报告可以使用固定名并在正文维护更新记录。
