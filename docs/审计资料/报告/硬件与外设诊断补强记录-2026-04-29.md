# 硬件与外设诊断补强记录

## 本轮补强

- 华睿相机 `MindVisionCamera` 的停止采集、关闭、销毁句柄、曝光、增益、触发模式、软触发失败不再静默吞掉异常，改为 `Debug.WriteLine` 记录诊断信息。
- GPU 探测 `GpuAvailabilityChecker` 的 CUDA version file、nvcc 查找、nvcc version 读取失败不再静默吞掉异常，改为 Debug 诊断。
- Modbus 连接池清理旧 `TcpClient` / master 失败时改为 `Logger.LogDebug`，保留无硬件环境的 fail-soft 行为。

## 当前边界

这些改动只把静默失败变成 Debug/Trace 级诊断，不改变运行时容错策略，也不会让无硬件测试环境因为 SDK、GPU、PLC 不存在而失败。

尚未完成：

- UI 或诊断 API 暴露统一的“不可用原因”。
- 相机 SDK 缺失、权限不足、设备占用的 contract/mock 测试。
- PLC/串口/GPU 全链路结构化诊断模型。
