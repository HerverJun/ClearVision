# 审计资料

这里保存审计、复核、外部评估和证据链材料。审计资料负责记录“结论从哪里来、怎么复现、还剩什么风险”，不作为零散计划堆放区。

## 分区

- [算子审计](./算子审计/README.md)：算子审计报告、周报、台账、启动计划和证据链；已完成 TODO 进入已关闭事项。
- [算法审计](./算法审计/README.md)：算法专项审计与评估材料。
- [系统审计](./系统审计/README.md)：项目现状、架构隐患和系统级复核材料。
- [报告](./报告/README.md)：性能、质量和专项报告。
- [外部审计](./外部审计/README.md)：ChatGPT、Kimi 等外部审计批次原始材料。

## 维护规则

- 内部审计结论必须有证据路径、测试入口、报告 ID 或复现说明。
- 外部审计材料按 snapshot 保存，不直接作为当前事实源。
- 审计产生的执行事项应转入 `../进行中/` 或算子审计修复清单。
