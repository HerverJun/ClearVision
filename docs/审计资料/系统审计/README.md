## 维护规则

- 系统审计只记录跨模块结论、架构风险、配置风险和长期治理建议。
- 已拆成执行计划的内容应链接到 `docs/进行中/` 或 `docs/归档/已关闭事项/`，不在系统审计中继续维护待办。
- 新审计报告必须写明审计日期、范围、证据路径、风险等级和后续入口。
