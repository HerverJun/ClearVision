# 仓库根目录规范

## 根目录原则

仓库根目录只保留产品工程、脚本工具、自动化入口和少量确实必须存在于根目录的运行时文件。计划、审计、模板、历史记录和过程材料统一进入 `docs/`，避免根目录继续堆积临时 Markdown、发布产物、测试输出和草稿分析。

## 当前顶层结构

| 路径 | 用途 |
|---|---|
| `Acme.Product/` | 主产品工作区 |
| `Acme.OperatorLibrary/` | 独立算子库工程 |
| `docs/` | 项目文档、计划、审计、模板、归档和算子资料入口 |
| `算子资料/` | 兼容镜像，原则上与 `docs/算子资料/` 保持一致 |
| `scripts/` | 自动化脚本与生成器 |
| `tools/` | 支撑工具与训练数据脚本 |
| `artifacts/` | 本地产物与测试输出 |
| `notebooks/` | 研究与实验笔记 |
| `vision.db*` | 本地数据库运行文件，保留到路径可配置后再迁移 |
| `tgconfig.json` | 本地工具配置 |

## docs 分工

| 路径 | 用途 |
|---|---|
| `docs/进行中/` | 当前计划、未闭环事项、待复核材料 |
| `docs/算子资料/` | 算子目录、名片、手册、版本记录和专项说明 |
| `docs/审计资料/` | 算子审计、系统审计、算法审计、外部审计和报告 |
| `docs/参考资料/` | 规范、指南、手册和 PR 门禁说明 |
| `docs/模板/` | 计划、任务、闭环记录、验收报告模板 |
| `docs/归档/` | 已关闭专题、历史资料、过期计划 |
| `docs/临时/` | 临时分析和过程草稿，定期清理 |
| `docs/图片/` | 文档图片、截图和配套素材 |

## 维护规则

1. 新计划放入 `docs/进行中/当前计划/`，未闭环排查放入 `docs/进行中/未闭环事项/`，待复核材料放入 `docs/进行中/待复核/`。
2. 过期计划不删除，合并说明后放入 `docs/归档/过期计划/`；已闭环专题放入 `docs/归档/已关闭事项/`。
3. 算子相关资料优先维护 `docs/算子资料/`；仓库根 `算子资料/` 仅作为兼容镜像，不作为新增资料的首选入口。
4. 生成产物应写到既定目录，不再手动复制出第二份索引；确需镜像时要在变更记录中说明。
5. 文档状态、命名、归档和镜像规则见 [文档治理标准](./文档治理标准.md)。
