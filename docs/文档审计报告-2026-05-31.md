# 文档审计报告（2026-05-31）

本次审计覆盖 `docs/` 下当前计划、算子资料、审计资料、归档资料、参考资料和模板，并抽查根目录 `算子资料/`、`docs/operators/` 等兼容镜像。

## 评分口径

| 维度 | 判定标准 |
|---|---|
| 完成情况 | 文档是否能说明当前状态、下一步、完成标准和归档状态 |
| 专业性 | 是否有单一入口、分区职责、命名规范、模板和生命周期规则 |
| 正确性 | 当前事实源是否一致，旧结论是否标注历史语境，链接是否有效 |
| 可追溯性 | 是否保留证据路径、测试入口、报告 ID、闭环说明或审计台账 |

## 后续准入规则

- 新增文档必须能从主入口或分区 README 追溯。
- 新增计划必须带 `status`、`doc_type`、`created`、`updated`，关闭时迁入归档并写闭环说明。
- 修改算子文档必须通过或同步 `scripts/OperatorDocGenerator`，避免只更新单个镜像。
- 外部审计建议必须转写到内部计划、审计报告或修复清单后才能执行。
