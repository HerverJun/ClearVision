# 归档

这里保存已经闭环、已被新计划替代或只作为历史参考的材料。归档不是丢弃，保留原文是为了后续追溯决策、证据和阶段结论。

## 分区

- [已关闭事项](./已关闭事项/)：阶段性完成报告和已收口专题。
- [过期计划](./过期计划/)：已被当前计划替代、不再直接执行的旧计划。
- [历史资料](./历史资料/README.md)：旧目录拆分、迁移来源和历史参考。
- [历史归档](./历史归档/README.md)：更早期的归档资料。

## 维护规则

- 归档文件允许保留当时的路径、状态和上下文。
- 如果需要重新启用某个计划，应新建当前计划并在新文档中引用旧归档，不直接覆盖历史正文。
- 历史快照中的断链和旧口径不默认修复；如影响当前结论，应在当前文档中新增勘误或转正说明。
