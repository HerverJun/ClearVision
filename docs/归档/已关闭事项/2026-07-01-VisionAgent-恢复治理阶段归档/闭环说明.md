## 代码推断

- AgentRun 事件权威是 `AgentRunEventStore` 和 `AgentRunEventStreamService`。
- Build terminal 到会话的投影由 `VisionAgentBuildTerminalProjector` 负责。
- Build terminal projection 的恢复和幂等 checkpoint 由 `VisionAgentBuildProjectionJournal` 负责。
- 会话工作台状态由 `ConversationalFlowService` 中的 `VisionAgentWorkspaceSnapshot` 持有。
- 正式 Project、Flow、GlobalVariables 保存由 `ProjectService` 和 `ProjectSaveCoordinator` 管理。
- 前端 `projectManager.js`、`globalVariablePanel.js` 和 `app.js` 只提供 UI 投影、编辑草稿和本机备份。

详细说明见 [`../../../进行中/Studio2/状态权威与恢复边界.md`](../../../进行中/Studio2/状态权威与恢复边界.md)。
