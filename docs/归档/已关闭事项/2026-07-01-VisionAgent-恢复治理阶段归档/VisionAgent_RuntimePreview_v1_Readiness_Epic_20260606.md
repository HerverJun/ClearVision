# Vision Agent RuntimePreview v1.0 Readiness Epic

## Scope

RuntimePreview v1.0 Readiness upgrades the v0.8 metadata-only Pilot into a governance platform for future real RuntimePreview trials. This release still does not implement a Real RuntimePreview adapter and does not touch real cameras, Station, image files, model files, PLC, packaging, deployment, downlink, or hot-load.

Allowed in this epic:

- metadata session lifecycle
- permission broker
- metadata resource broker
- developer-hidden Pilot Console
- metadata-only simulated execution harness
- append-only audit trail
- report archive
- Real RuntimePreview RFC
- tests, benchmark, artifact/source scan, CI evidence

## Architecture Audit

v0.8 responsibilities:

- `RuntimePreviewPilotConfig`: safe metadata-only pilot config under app config.
- `RuntimePreviewPilotResourceCatalog`: metadata catalog from AppConfig, AiConfigStore, workflow draft, fixture fallback.
- `RuntimePreviewPilotReadinessGate`: ready / not_ready / denied.
- `RuntimePreviewPermissionGate`: Agent tool runtimePreviewConsent and RuntimePreview permission.
- `RuntimePreviewResourceAllowlistResolver`: resource allowlist and dangerous resource denial.
- `PilotRuntimePreviewAdapter`: readiness first, then metadata result, offline fallback, or dangerous deny.
- Settings endpoint/UI: config/catalog/readiness management.

Observed gaps:

- Endpoint access was separate from Agent tool permission.
- Session lifecycle did not exist.
- Catalog items were exposed directly; future real resources needed an intermediate handle boundary.
- Readiness and adapter output shared similar metadata but had no audit chain.
- Reports were generated by quality tooling, not by a RuntimePreview session flow.
- Pilot UI was a config panel, not an operational console.

v1.0 convergence:

- `RuntimePreviewPermissionBroker` owns endpoint access, consent, pilot enabled, metadata-only mode, session transition, and dangerous denial.
- `RuntimePreviewResourceBroker` maps catalog items to metadata-only resource handles.
- `RuntimePreviewSessionStore` captures safe session summaries.
- `RuntimePreviewAuditTrail` appends redacted audit events.
- `RuntimePreviewReportArchive` stores metadata reports.
- `RuntimePreviewSimulatedExecutionHarness` runs create -> catalog -> readiness -> authorize -> simulate -> report without real resources.

## Session Lifecycle

Statuses:

- `created`
- `configured`
- `readiness_checked`
- `authorized`
- `simulated`
- `completed`
- `denied`
- `failed`
- `cancelled`

Session summary fields:

- `sessionId`
- `workflowDraftHash`
- `pilotConfigRevision`
- `catalogSnapshotId`
- `readinessStatus`
- `permissionStatus`
- `auditEventIds`
- `reportId`
- `metadataOnly=true`
- `realResourcesTouched=false`

Lifecycle behavior:

| Transition | Broker / service | Result |
| --- | --- | --- |
| create | `RuntimePreviewSimulatedExecutionHarness.CreateMetadataSession` | session and catalog audit events |
| configure | config hash only | no raw paths or secrets |
| readiness | `RuntimePreviewPilotReadinessGate` | ready/not_ready/denied |
| authorize | `RuntimePreviewPermissionBroker` | consent/admin/pilot/mode/readiness decision |
| simulate | `RuntimePreviewSimulatedExecutionHarness` | metadata timeline and zero-byte artifact summary |
| complete | harness | report generated |
| deny | broker/readiness | no simulation artifact |
| fail | future failure path | report still redacted |
| cancel | harness + broker transition | append cancellation audit event |

## Permission Broker Matrix

| Gate | Allow | Deny |
| --- | --- | --- |
| endpoint access | admin session | non-admin session |
| developer hidden UI | admin plus optional developer UI header | ordinary user hidden by default |
| runtimePreviewConsent | true | consent missing, pending action |
| RuntimePreview permission | present in context | missing permission |
| pilot enabled | `enabled=true` | disabled |
| mode | `metadata_only` | any other mode |
| readiness | ready | not_ready or denied |
| dangerous resource | never allowed | path/file/modelPath/templatePath/Station/PLC/base64/image bytes |
| session transition | non-terminal session | completed/denied/failed/cancelled session |

## Resource Broker Matrix

| Catalog resource | Handle allowed | Real value exposed |
| --- | --- | --- |
| camera | metadata handle | no IP, serial, SDK handle |
| model | metadata handle | no BaseUrl, API key, model file path |
| template | metadata handle | no template file path |
| flow | metadata handle | no raw deployment artifact |
| resourceRoot | metadata handle | no filesystem path |

All handles are logical metadata handles. They are not resource capabilities.

## Pilot Console

The AI settings RuntimePreview Pilot section is upgraded to `RuntimePreview Pilot Console v1.0` and remains hidden unless `localStorage.cv_ai_agent_dev_ui=true`.

Console capabilities:

- config edit
- catalog browser
- catalog-driven allowlist inputs
- readiness execution
- session list
- create metadata session
- simulate metadata session
- load report
- cancel session
- simulated timeline display
- audit timeline display
- report preview/export surface

The console redacts values with the existing UI sanitizer and does not print keys, paths, IP/BaseUrl values, Station, PLC, or base64 markers.

## Metadata-Only Simulated Harness

The harness is not a wrapper around `OfflineRuntimePreviewAdapter`. It creates a session, snapshots catalog handles, runs readiness, runs broker authorization, records audit events, creates a simulated metadata timeline, and archives a report.

E2E matrix:

| Scenario | Expected result |
| --- | --- |
| ready + authorized | completed report, `previewReady=true` |
| missing allowlist | denied report, pending action, `workflowDraftAllowed=true` |
| dangerous path/base64/Station/PLC | denied, no simulation artifact |
| missing consent | permission denied with pending action |
| cancel created session | `cancelled` status and audit event |
| completed session cancel | terminal transition denied |

All simulation outputs keep:

- `metadataOnly=true`
- `realResourcesTouched=false`
- `binaryIncluded=false`
- `capturedRealFrame=false`
- `loadedModelFiles=false`
- `accessedHardware=false`
- `stationTouched=false`

## Audit And Report

Append-only audit event types:

- `session_created`
- `config_changed`
- `catalog_loaded`
- `allowlist_changed`
- `readiness_checked`
- `permission_denied`
- `permission_granted`
- `simulation_started`
- `simulation_completed`
- `report_generated`
- `session_cancelled`
- `session_failed`

Audit payloads are serialized through the governance redactor. Reports archive session, handles, readiness, permission decision, audit events, and simulation result. Reports do not persist image bytes, raw paths, model files, Station data, PLC addresses, or secrets.
