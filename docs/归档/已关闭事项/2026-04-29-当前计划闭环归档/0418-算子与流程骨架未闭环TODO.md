## 本轮落地记录（2026-04-29）

- `ImageStitchingOperator` 的 `BlendMode=MultiBand` 已落地为 Laplacian pyramid / multi-band blend，不再是 `FeatherBlend` 别名，并输出 `BlendImplementation`。
- `TimerStatisticsOperator` 已明确状态作用域为 `OperatorInstance`，新增 `StateTtlMinutes` 与 `Reset`，并输出状态 diagnostics。
- `SubpixelEdgeDetectionOperator` 本轮选择保持非工业级定位，metadata 与输出 diagnostics 明确 `NonIndustrialReference` / `NotIndustrialMetrologyModel=true`。
- 验证：相关算子测试已并入本轮定向测试批次，最终 97/97 passed。

## 已见闭环证据

- `PixelToWorldTransform` 已拒绝反向/非稳定 ray-plane scale，并在 PixelToWorld 输出保留 `Point3d.Z`。
- `NPointCalibration` 仿射/透视路径已使用 `Point2d` / double；`TranslationRotationCalibration` 已解析并应用 angle constraint。
- `AdaptiveThreshold`、`CannyEdge`、`DistanceTransform`、`HistogramEqualization` 已通过 `OperatorImageDepthHelper` 处理 12/16-bit 路径。
- `AnomalyDetection` 推理已以 feature bank 元数据为准；`ColorDetection` 的 `LabDeltaE` 缺完整参考色时 fail-closed；`SurfaceDefectDetection` 对齐失败时不再继续差分。
- `ShapeMatching` 已有 rotation-scale pyramid 搜索与 pose 输出；`PPFMatch` 已把 `IsMatch` 绑定到最终 verification passed，避免 `IsMatch=true` 且 `FailureReason` 非空。
- `EdgePairDefect` 已沿配对边法向搜索本地边缘点；`FrameAveraging` 中值路径已改为逐像素 quickselect，不再整栈拼接全排序。
- `JsonExtractor` 使用 `InvariantCulture`；`FFT1D` 已保留 16-bit 振幅尺度；`StatisticalOutlierRemoval` 已切到 KD-tree KNN。
- `RoiTransform` 已接受 `CenterX/CenterY`、`ReferenceX/ReferenceY`、`BoundingBox`、`Corners` 等 pose 形状；`P2MatchingResidual_baseline` 显示 `PlanarMatching` / `LocalDeformableMatching` / `ShapeMatching` 72/72 passed。

## P1：ImageStitching MultiBand 契约仍未落地

### 未闭环证据

- `ImageStitchingOperator.BlendWarpedImages(...)` 中 `BlendMode=Linear` 和非 Linear 分支目前都返回 `FeatherBlend(...)`。
- 算子参数暴露了 `MultiBand`，但实现没有真实多频段融合路径。

### TODO

- [x] 实现真实 multi-band / Laplacian pyramid blending，或下调参数契约，移除 `MultiBand` 选项。
- [x] 增加曝光差、纹理接缝、重叠区域宽窄变化的拼接测试。
- [x] 在输出 diagnostics 中记录实际 blend implementation，不只记录参数值。

### 验收标准

- `BlendMode=MultiBand` 与 `BlendMode=Linear` 在接缝/曝光差场景下走不同实现路径。
- 新增测试能证明 MultiBand 对重叠 seam 的输出不是 FeatherBlend 的别名。

## P2：TimerStatistics 状态生命周期治理不足

### 未闭环证据

- `TimerStatisticsOperator` 使用实例级 `ConcurrentDictionary<Guid, TimerState>`，按 `operator.Id` 累积状态。
- 当前没有 TTL、显式 reset 输入、session/run 维度隔离或清理机制。

### TODO

- [x] 明确 TimerStatistics 的状态作用域：operator、flow run、session 三者选一，写入 diagnostics。
- [x] 增加 `StateTtlMinutes` 或 `Reset` 输入/参数，支持长运行清理与显式归零。
- [x] 补测试：不同 operator id 不串线；同 operator 多次运行符合预期；TTL/reset 后 Count/TotalMs 归零。

### 验收标准

- 长时间运行不会无限累积旧 `TimerState`。
- 计时语义在流程重复执行、会话切换、显式 reset 下可预测。
