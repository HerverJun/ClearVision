# ClearVision 项目总览

更新日期：2026-08-28

ClearVision 是一个面向工业视觉检测的 .NET 8 平台工程。它不是单一 OpenCV demo，而是把图像采集、预处理、检测、测量、标定、AI 推理、PLC/通信、流程编排、Station 现场同步和算子证据治理放在同一套工程骨架中。

## 工程结构

| 区域 | 当前职责 | 入口 |
| --- | --- | --- |
| Desktop Studio | Windows 桌面应用、WebView2 UI、本地 API、项目/流程管理 | `ClearVision.Product/src/ClearVision.Product.Desktop` |
| Runtime | 流程执行、运行包导出、Station 可加载运行面 | `ClearVision.Product/src/ClearVision.Product.Runtime` |
| Station | 现场端同步、健康、结果摘要、命令与包部署 | `ClearVision.Product/src/ClearVision.Product.Station` |
| Core/Application/Infrastructure | 领域模型、服务、仓储、算子实现 | `ClearVision.Product/src` |
| OperatorLibrary | 独立 NuGet 包形式的公开算子库 | `ClearVision.OperatorLibrary` |
| Quality | 算子矩阵、数据集/回放/gate 报告 | `quality` |

## 质量口径

ClearVision 现在使用两条线描述算子成熟度：

- 功能成熟度：算子是否存在、是否在正式目录中、是否能通过基本契约或 smoke 路径。
- 证据成熟度：是否具备 contract、golden、dataset、field replay、真实现场签核等证据。

正式发布材料不得把 public dataset、semi-synthetic、field-substitute replay 或 dry-run smoke 写成真实产线签核。真实产线签核必须有现场样本、硬件 profile、数据版本、报告 ID 和审批记录。

## 当前发布边界

- SDK：`global.json` 以 `.NET SDK 9.0.300` 为基线，`rollForward` 为 `latestPatch`；仅接受 `9.0.300`–`9.0.399`，本地入口与 CI 共用 `scripts/validate-dotnet-sdk-policy.ps1` 拒绝跨 feature band 漂移。
- 依赖：Product 与 OperatorLibrary 使用中央包版本管理；OperatorLibrary 使用 lock file 和 locked restore。
- 数据库：Desktop 初始化已从 `Program.cs` 拆到数据库初始化器；当前采用 migration-light 机制，正式 release 前仍应继续补标准 EF migrations。
- 前端实时：结果页和检测页统一走 inspection SSE/history 语义。
- Station：Station 同步是 opt-in；结果摘要允许背压丢弃以保护检测主路径，本地运行优先。
