# ClearVision 项目总览

> 更新时间：2026-04-28
> 口径：以当前仓库代码、已生成算子资料、质量治理文档和本地工作区状态为准。

## 一句话定位

ClearVision 是一个 .NET 8 工业视觉检测与流程编排项目。它把传统视觉、测量、标定、匹配定位、AI 推理、通信、数据处理和流程控制封装成统一 Operator 体系，并通过算子目录、算子名片、质量矩阵和 golden/contract baseline 逐步把“能跑”推进到“可证明”。

## 质量进度审查

当前质量治理已经从“列清单”进入“证据链补强”阶段：

- C 级算子救火已在 Quality Flywheel 中记录为完成，13 个 C 级算子已有 runner 或 contract baseline evidence。
- Region/Morphology 名片 TODO 已清零，Region/Morphology 相关算子已有 100 条 synthetic golden cases 级别的报告入口。
- TemplateMatching、CaliperTool、GradientShapeMatch、FFT1D、InverseFFT1D、FrequencyFilter 等核心算子已产出 baseline / triage 证据。
- AI 检测方向已有 AnomalyDetection MVTec AD Lite baseline、DeepLearning YOLO 输出契约、SemanticSegmentation、EdgePairDefect、DualModalVoting 等 contract baseline。
- Calibration synthetic geometry baseline 已完成，覆盖 9 个校准算子、216/216 passed，并与现有 .NET 校准测试证据衔接。

本地工作区中还有未提交的质量推进痕迹，例如 `operator_quality_matrix.md` 已推进到 A=138 / B=17、Golden Test=39，并新增了 ResultJudgment、TimerStatistics、MathOperation 等合同/基线评测产物。为避免把现有工作区其他改动带入本次小提交，这些 runner 与报告产物本次不随 README/总览文档一起提交。

## 仍需谨慎的边界

- 155 个算子已有统一目录和名片，但不是每个算子都有同等级的公开数据集、现场样本和长期稳定性证据。
- 当前质量分数适合内部治理优先级，不应直接等同于外部 benchmark 结论。
- GPU、4K、大批量吞吐、峰值内存、长时泄漏和跨硬件复现实验仍需要持续补证。
- 分类 taxonomy 仍有中英混合，例如 `AI Detection` / `AI检测`、`Region` / `Morphology` 并存，后续适合做一次兼容式归一化。
