## Workspace State Map

The Flow workspace is one mounted capability with one lifecycle owner. Its visual reference must preserve the current ownership boundaries:

- top project/version/save/run context;
- operator discovery rail and FlowCanvas;
- selected-node Inspector and parameter validation;
- Preview/ImageCanvas/ROI tools;
- result summary, structured output, and run details modal;
- global variables, templates, final decision, and runtime package entry points.

Generated references must not invent a second canvas, save path, execution channel, event bus, or state authority.
