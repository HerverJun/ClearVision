## 二维平面比例偏移标定向导问题诊断
- 用户反馈标定向导无法执行（实际是执行成功但 RMSE=16mm 严重超标，标记"需要复核"）
- **根因**：标定点的物理坐标填写错误——5个图像上的散乱点被赋予了共线的物理坐标 (10,10)~(50,50)，与对角比例偏移模型的假设（PixelX↔PhysicalX 正相关、PixelY↔PhysicalY 正相关）完全矛盾
- 向导使用的是 X/Y 轴独立线性回归模型（`PlanarScaleOffsetCalibrationService.cs`），非完整仿射
- 验收阈值：RMSE ≤ 0.15mm，单轴误差 ≤ 0.10mm
- 如需旋转/剪切补偿，应使用 NPointCalibrationSolver 的 Affine 模式（OpenCV RANSAC）
- 补充：用户确认标定点/物理坐标是乱填的测试数据，结论为功能正常（验收拦截生效）

## GR 机械臂是否支持 SSH 控制(调研结论)
- 通信总线手册 v3.0 仅定义两种对外通信:EtherCAT(控制器作主站连伺服/IO 从站,内部总线)与 ModbusTCP(控制器作服务器,端口502,对外控制通道)。无 SSH/Telnet/远程登录/shell 任何控制方式。
- PDF 二进制里搜到的 "SSH"/"ssh" 字节位于压缩流/字体数据乱码中(pdfminer 全文 22410 字符与 tmp 提取文本均无 SSH 字样),纯属字节序列巧合,非正文内容。
- 实测 `172.16.87.12:22` → CLOSED/TIMEOUT,仅 `:502` OPEN → 控制器未开放 SSH 服务。
- 结论:**不支持用 SSH 从电脑控制机械臂**;控制正道是 ModbusTCP(已连通)。即便对端开 SSH,进去也只是 Linux shell,不能直发运动/IO 指令。
