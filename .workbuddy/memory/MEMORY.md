# ClearVision 项目长期记忆

## 现场设备:GR 机械臂(珠海格力智能装备,GMEEMC06A 控制器)
- 直连网线,机械臂 LAN2 IP **172.16.87.12:502**(ModbusTCP 服务器,默认值),MAC 6c-30-2a-46-63-ac;本机网卡 172.16.87.222/24。已 ping 通,502 端口开放。
- 仅支持保持寄存器,功能码 03/06/0x10;FLOAT 大端占 2 寄存器。
- 关键地址:300+ 笛卡尔坐标、320+ 关节 J1-J6、437-450 状态字、442 报警码、501 倍率、502-505 DIDO、1000-1009 外部控制(需示教器开"外部自动→Modbus 控制")、0~124 用户自定义交互区、601 产量计数。
- Modbus 开关默认关闭:示教器 菜单→控制面板→监控→Modbus 开关;IP/端口改动需重启。
- **502 端口是单连接且服务器不主动回收**:客户端 close() 后控制器不回 FIN,本机连接会卡在 FIN_WAIT_2,服务器侧连接槽一直被占;多次连接后新连接只能 TCP 握手、FC03 读请求被**静默丢弃(无响应)**。诊断:netstat 见多个 172.16.87.12:502 处于 FIN_WAIT_2;TCP 能连但读静默 = 单连接槽被占(非开关关闭)。**最快恢复:示教器 Modbus 开关关→开,强制服务器释放所有连接**。Windows FIN_WAIT_2 默认约 240s 超时后内核才回收。写脚本务必每次用完 close(),且避免并行/重复连接。
- 完整寄存器表和示教器操作备忘:`docs/GR机械臂-ModbusTCP速查手册.md`
- 手册 PDF 在桌面:`GR机器人通信总线手册 v3.0-1.pdf`、`GR机器人示教器手册 v3.0-1.pdf`;提取的纯文本在 `tmp/` 下同名 .txt。
- **不支持 SSH/Telnet 远程登录控制**:通信总线手册 v3.0 仅定义 EtherCAT(控制器作主站连伺服/IO 从站,内部总线)与 ModbusTCP(对外控制通道,端口 502)两种对外通信;PDF 内 "SSH" 字节系压缩流/字体数据巧合,非正文内容。实测 172.16.87.12:22 关闭、仅 502 开放。控制机械臂正道是 ModbusTCP(已连通),而非 SSH。
- **FTP(21)开放且匿名可读写**:本机网线直连 172.16.87.12:21,匿名(user=anonymous / 空密码)+相对路径可逐级进入 robot-folder/MyProject/test1 并 RETR 下载 .proc/.pro 程序(实测读到 MainFile.proc:Jointtarget/MovJ/Proc main/SocketReceive)。**可写性已验证:匿名 MKD/RMD 与 STOR/DELE 均成功 → 匿名可建目录/上传文件**。要点:匿名须用**相对路径**(robot-folder 而非 /robot-folder)且密码留空,否则 550;控制器 FTP 并发连接数有限,开着资源管理器 FTP 窗口时 Python 新连会超时,需先关。手册未记载 FTP 凭据,但匿名即可读写。**安全提示:匿名可读写=任何人网线直连可拷走并替换机器人程序,产线务必限制/改账号。** 与 SSH 不同:SSH(22)关闭、FTP(21)开着且匿名可读写。
